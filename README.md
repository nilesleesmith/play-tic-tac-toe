# Tic-Tac-Toe

A simple JavaScript Tic-Tac-Toe game for two players.

## About

This project creates a two-player Tic-Tac-Toe game in the browser.

Players take turns selecting squares using X and O.

The game tracks occupied board positions, checks for winning combinations, detects ties, keeps score, and resets the board after each completed game.

## Features

- Two-player Tic-Tac-Toe
- Player X and Player O
- Tracks the current player's turn
- Prevents players from selecting an occupied square
- Checks horizontal winning combinations
- Checks vertical winning combinations
- Checks diagonal winning combinations
- Detects tied games
- Keeps score between rounds
- Clears the board after a win or tie
- Updates the page dynamically as the game is played

## Running the Project

1. Clone or download the repository.
2. Open `index.html`.
3. Player X selects a square.
4. Player O selects a square.
5. Continue taking turns until a player wins or the board is full.
6. The board resets after a completed game.
7. The player scores remain available for additional rounds.
8. Open the browser developer tools and select the Console to view logged data.

## Purpose

This project was created while practicing JavaScript objects, classes, arrays, functions, conditionals, loops, event listeners, and DOM manipulation.

The focus is on organizing game state and behavior while building the logic required for turns, board positions, winning combinations, ties, scoring, and restarting the game.
